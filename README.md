# Калькулятор-конвертер

Это небольшой проект на Python, в котором я сделал калькулятор и конвертер единиц измерения.

Программа работает через командную строку. Это значит, что не нужно открывать отдельное окно и что-то вводить через input(). Команды сразу пишутся в терминале.

## Что умеет программа


### Калькулятор

Калькулятор умеет работать с целыми и дробными числами.

Поддерживаются обычные операции:

- сложение `+`
- вычитание `-`
- умножение `*`
- деление `/`

Также я добавил дополнительные операции:

- целочисленное деление `//`
- остаток от деления `%`

Можно использовать положительные и отрицательные числа, а также унарные знаки `+` и `-`.

Калькулятор умеет правильно учитывать порядок действий. Например, в выражении:

- `2 + 3 * 4`. Cначала выполняется умножение, а потом сложение.
Результат: 14.0

Пробелы в выражении не мешают работе программы. Например:

- `2 + 3 * 4`
и
- `  2    +  3 *  4`

обрабатываются нормально.

Примеры работы калькулятора

- Обычное сложение:
`python -m toolkit calc "2 + 3"`
Результат:
5.0

- Приоритет операций:
`python -m toolkit calc "2 + 3 * 4"`
Результат:
14.0

- Работа с отрицательными числами:
`python -m toolkit calc "-5 + 2 * -3"`
Результат:
-11.0

- Целочисленное деление:
`python -m toolkit calc "10 // 3"`
Результат:
3.0

- Остаток от деления:
`python -m toolkit calc "10 % 3"`
Результат:
1.0


### Конвертер

Кроме калькулятора в программе есть конвертер единиц измерения.

Он работает с тремя группами единиц.

- Длина

Поддерживаются:
mm — миллиметры
cm — сантиметры
m — метры
km — километры

Например:

`python -m toolkit convert 100 --from cm --to m`
Результат:
1.0

- Масса

Поддерживаются:
g — граммы
kg — килограммы

Пример:

`python -m toolkit convert 2 --from kg --to g`
Результат:
2000.0

- Температура

Поддерживаются:
c — градусы Цельсия
f — градусы Фаренгейта
k — Кельвины
Пример:
`python -m toolkit convert 0 --from c --to f`
Результат:
32.0

- Свойства калькулятора:

Регистр единиц не имеет значения. Например, cm, CM и Cm будут восприниматься одинаково.

Температуры ниже абсолютного нуля программа не принимает.

Также нельзя переводить единицы из разных групп между собой. Например, нельзя перевести сантиметры в килограммы.


### Как установить проект

Сначала нужно перейти в папку проекта и создать виртуальное окружение.

После этого проект можно установить командой:
`python -m pip install -e`

После установки программа запускается через:
`python -m toolkit`


### Основные команды

- Для запуска калькулятора используется:
`python -m toolkit calc "EXPRESSION"`

- Для запуска конвертера:
`python -m toolkit convert VALUE --from UNIT --to UNIT`

- Для просмотра доступных команд:
`python -m toolkit --help`

- Также можно посмотреть справку отдельно для каждой команды:
`python -m toolkit calc --help`
`python -m toolkit convert --help`


### Как работает калькулятор

Я разделил работу калькулятора на несколько частей.
Сначала программа получает строку с выражением и разбирает её на отдельные элементы.

- Например:

`-5 + 2 * -3`

после этого становится набором чисел и операторов.
Потом программа проверяет, что выражение записано правильно. Например, она не должна принимать пустую строку, неизвестные символы, два оператора подряд или выражение с пропущенным оператором.

После проверки программа выполняет вычисления.
Сначала обрабатываются операции:

`*`
`/`
`//`
`%`
а потом:
`+`
`-`

Благодаря этому правильно работает приоритет операций.

Я не использовал `eval(), exec()` и готовые библиотеки для разбора арифметических выражений. Калькулятор самостоятельно разбирает строку и выполняет вычисления.


### Обработка ошибок

Программа специально проверяет неправильный ввод.

Например, ошибкой будут:

- пустое выражение
- неизвестный символ
- пропущенный оператор
- два оператора подряд
- деление на ноль
- неизвестная единица
- несовместимые единицы
- температура ниже абсолютного нуля

При ошибке программа выводит сообщение в stderr и завершает работу с кодом `2`.
При успешном выполнении программа завершается с кодом `0`.


### Структура проекта

Основная часть программы находится в папке src/toolkit.

.
├── pyproject.toml
├── README.md
├── src/
│   └── toolkit/
│       ├── __init__.py
│       ├── __main__.py
│       ├── calculator.py
│       ├── converter.py
│       └── errors.py
└── tests/
    ├── __init__.py
    ├── test_calculator.py
    └── test_converter.py

- calculator.py отвечает за работу калькулятора.
- converter.py отвечает за перевод единиц измерения.
- __main__.py нужен для запуска программы через команду: `python -m toolkit`
- errors.py содержит отдельный тип ошибки для проекта.

В папке tests находятся тесты калькулятора и конвертера.


### Тестирование

Для проверки программы я использовал библиотеку `pytest`.

Чтобы запустить все тесты, нужно выполнить:
`python -m pytest`

Тесты проверяют обычную работу калькулятора и конвертера, а также ошибки.
Для калькулятора проверяется работа арифметических операций, приоритет операций, дробные числа, отрицательные числа, пробелы, // и %.

Отдельно проверяются неправильные выражения и деление на ноль.

Для конвертера проверяются разные единицы длины, массы и температуры, регистр букв, несовместимые единицы и некорректные температуры.

Также есть отдельные тесты CLI. Они запускают программу почти так же, как если бы команда была введена вручную в терминале, и проверяют результат выполнения и код завершения.


### Проверка качества кода

Для проверки кода используется Ruff:
`ruff check`

Также перед созданием коммита автоматически запускаются дополнительные проверки через `pre-commit`.

В них входит проверка типов через mypy, проверка Ruff и несколько проверок файлов.


### Дополнительные возможности

В базовую версию я также добавил операции:

`//`
`%`

Их работа проверяется не только для обычных чисел, но и для отрицательных значений.

- Например:

`-10 // 3 = -4.0`
и:
`-10 % 3 = 2.0`

Для этих операций также предусмотрена ошибка при попытке деления на ноль.


### Итог

В итоге получился небольшой Python-пакет, который умеет считать арифметические выражения и переводить значения между единицами измерения.

Программа запускается через командную строку, проверяет ошибки, имеет автоматические тесты и отдельные проверки качества кода.
